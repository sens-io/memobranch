# Design

Add optional validFrom/validUntil fields only to ordinary MemoryMeta. Omission means unknown, not creation time. Explicit annotation replaces both nullable bounds, checks expectedRevision under the existing transaction lock, preserves evidence/body/status, increments revision and logs only opaque identity. Revoked records cannot be annotated back into use. Existing records need no rewrite or migration; old writers must not be mixed with annotated data because they do not enforce these fields.

memoriesAt(at, options) is a settled read over current canonical ordinary memories, not Git history or a model answer. Current tenant/read/scope/sensitivity, opt-in confidential selection, evidence access, expiry/revocation/erasure and pending-recovery checks precede filtering/counting/pagination. Superseded and conflicted retained records can appear with explicit warnings, never as active assertions. Missing effective intervals are excluded by default. Results expose the latest reviewer annotation and retained revision, including when recorded/updated/validated, not what was known at the requested date.

Use strict timezone-bearing ISO timestamps at millisecond precision, normalize to UTC, reject equal/reversed intervals. The start is inclusive and end exclusive. Current retrieval checks the interval before scoring/embedding and again against canonical content; bump only the derived index format. Complete recall records keep the dates. Legacy Wiki projections include explicit interval conditions and the earliest end/expiry, and become unavailable outside the interval; linked derived pages remain subject to transitive checks. Generated resident Markdown is a last-write projection, not a clock-driven live query: show explicit dates and direct consumers to current APIs.

No new model prompt workflow, model dependency, background timer or automatic fact lifecycle mutation. Annotation does not repair supersession or close/split other intervals. Dated results report uncertainty instead of silently choosing a winner. The Web routes retain strict authentication/Origin/Host/confirmation checks and do not acquire a second read lock around a core-owned settled read.
