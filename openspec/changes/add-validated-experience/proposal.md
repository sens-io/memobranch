# Validated experience and explicit skill export

## Why
Existing episodes and procedure candidates do not provide an auditable link from
an execution trace to cross-task checks and a reusable skill. A successful anecdote
is insufficient evidence for automatic procedural knowledge.

## What changes
Add structured immutable experience evidence, a signed procedure proposal, a
trusted-host validation callback and an explicit, read-only skill export. Reuse
existing evidence, encryption, transactions and local proof keys. Validation
records are evidence, not canonical memories. Existing manual memory approval is
unchanged. Start with the library; track CLI and management adapters separately.

No automatic installation, execution, promotion, cloud account, permission grant,
external evaluator selection or model call.
