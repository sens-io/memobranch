# Explicit knowledge availability observations

Add a local, signed immutable observation that selected committed Wiki pages and
their dependencies were readable by this system. Reconstruct selected versions
at a requested time only from those observations, never from Git timestamps or
page creation dates. Legacy or unverifiable history remains explicitly unknown.

This is evidence of local availability, not a claim that an agent read, understood
or believed a fact. The host clock and local proof key are trusted operational
inputs, not independent timestamping. No external service or account is added.
