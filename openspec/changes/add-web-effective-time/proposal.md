# Web management of explicit memory time

## Why
Effective-time annotation and dated retained-record reads exist in the core and authenticated HTTP, but the console cannot perform or explain them.

## What changes
- Display ordinary-memory interval bounds and distinguish lifecycle status from whether its explicit interval applies now.
- Let current reviewers edit both nullable bounds with a canonical revision, explicit comparison/confirmation and fresh reads after saving.
- Add explicit UTC date selection, exact-key filtering, optional unknown intervals and authorized pagination using the existing dated-read route.
- Preserve provenance, uncertainty, tenant/permission/confirmation checks and in-memory authentication. Do not infer dates or introduce model calls.

## Not included
PDF parsing, historical Wiki reconstruction, automatic scheduling/supersession, confidential selection in Web dated reads, automatic approval, push or npm publication.
