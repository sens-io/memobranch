# Design

Extend the self-contained existing console and logo-derived visual language, without another framework, dependency, model request or credentials option. List summaries add only the authorized ordinary memory's revision and optional time bounds. Existing HTTP routes and canonical transactions remain authoritative.

Native datetime-local controls are explicitly labelled UTC, not interpreted in the browser's local timezone. Preserve seconds and milliseconds, validate calendar values without Date rollover, normalize to timezone-bearing ISO for the API. Blank annotation bounds mean unknown; clearing them removes restrictions and requires explicit confirmation. Never initialize them from creation/validation time.

The detail view loads the actual current revision. Only a reviewer of a non-revoked ordinary memory sees the editor. Show old/new bounds and revision before confirming; send both nullable bounds and the displayed revision. Cancellation sends nothing. After a failed/ambiguous mutation, remove the old submit controls and require a fresh read; do not silently retry or refresh only the revision. After success, report the saved revision/commit separately from follow-up refresh failures, reload the detail and refresh the originating list/query. A closed or logged-out dialog must not send or render late work.

The dated view is a distinct read-only panel for ordinary retained records, not full-text search or historical Wiki. Default unknown inclusion off, exact-key filter optional. Explain latest revision/annotation and current withdrawal restrictions. Keep returned lifecycle, evidence, complete body and uncertainty visible. Opening a result rereads the current document. Pagination follows the server's actual capped limit; editing unsubmitted filter fields cannot silently change page criteria. New queries supersede and abort old reads; leaving the page or disconnecting discards late responses.

Time applicability is not lifecycle or factual certainty. Render unknown endpoints, not-yet-effective, ended, and currently within known bounds as separate textual labels; superseded/conflicted/revoked records retain warnings. No automatic refresh or promise that a displayed read remains current forever; show an explicit refresh action. Existing generated resident files remain last-write projections.

Verify shipped event handlers with deterministic DOM/network tests, real authenticated HTTP with current authority/revision checks, desktop/narrow browser interactions and installed Node20.0.0/22 consumers. Retain both Git-default complete checks and isolated read-only committed-candidate review.
