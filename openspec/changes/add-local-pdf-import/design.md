# Design

Use a pinned Node20-compatible bundled PDF.js parser only in a dedicated worker with a hard deadline, cancellation, per-worker JavaScript heap limits and sequential pages. Disable evaluation, XFA, fonts/images and network fetch; never invoke embedded JavaScript, actions, attachment extraction or linked URLs. Bound source bytes, pages, text items and extracted characters. Reject unreadable/password-encrypted and entirely textless documents rather than reporting successful extraction. Empty pages in mixed documents retain their page number and an explicit OCR-not-run warning. Extracted reading order may differ from the visual page; the source is evidence, not a verified fact. Worker resource limits are not an operating-system sandbox or a hard limit on all native/ArrayBuffer allocations; this local capability must not be exposed as an untrusted multi-tenant upload service.

PDF originals remain separate from extracted text within one canonical evidence Markdown envelope: a bounded base64 field with exact bytes and SHA-256, plus page count and parser descriptor. The hashed body includes the original digest, parser and page labels. Validate original bytes against that digest and the body header; bind the extraction digest to the complete body. Encrypt the entire record when required. Existing append-only Git synchronization, recovery, backups and per-record key erasure therefore cover the original and extracted text together, without extending remote file types. Model source/context DTOs must omit original bytes, not serialize all metadata indiscriminately.

PDF evidence uses a distinct version-3 digest domain. Removing its original or changing its digest version cannot silently turn it into ordinary text evidence. Existing version-1/2 migration remains unchanged; no automatic rewrite of old evidence. Older readers reject version-3 evidence and must not be mixed with new writers. Evidence retains its existing immutable-source retention: withdrawing/erasing a derived memory does not erase its raw evidence or PDF. This increment adds no source deletion API; destroying an encrypted evidence key through the existing key manager makes both its text and original unreadable.

Only explicit local API/CLI paths are supported. Resolve and bound file reads, refuse symlinks/nonregular sources and changes during reading. Preview returns hashes/counts/warnings without page text or encoded bytes. Apply authorizes tenant/write/scope/sensitivity before touching sources, repeats preview, compares the whole manifest and captures evidence only with extraction disabled. Cancellation before capture leaves no write; cancellation after a ready commit must preserve the existing committed-operation error details. Identical retry returns the existing evidence and no extra commit; changes produce another immutable source version. Public reads of an original must go through the existing authorized record read.

Retain Node20.0.0 and both Git-default full checks, actual installed consumers, adversarial source/plan/digest tests and independent committed-candidate review. No claim of visual extraction fidelity or OCR; test fixture rendering is separate from parser and safety regressions.
