# Web 手工 Wiki 合并：实现与验证记录

日期：2026-10-21。项目：`sens-io/memobranch`。来源分支：`kevin/knowledge-expansion`。

## 本批交付

Web 管理界面新增“知识合并”：在同一个本地资料库内读取完整的历史和当前 Wiki，人工编辑正文、摘要和标题，检查完整签名方案，再单独确认保存。生成方案不调用模型，不自动批准，也不修改原始来源。操作说明见 [Web 合并指南](web-manual-merge.md)。

新增 `wiki-snapshot` 和 `merge-prepare` 两个经过认证的固定资料库接口；沿用现有预览、批准、权限、敏感内容选择、请求取消和核心事务处理。完整结果和可再次提交的批准请求必须符合现有大小限制，不能靠截断正文通过检查。页面切换、内容编辑或输入变动后，旧方案不能继续批准。保存结果不明确时只提供显式的原方案重试，不自动提交新方案。

遵循 agent-engineering 的权限、内容生命周期和知识来源检查要求；界面按 frontend-design 保留项目 Logo 配色，并提供窄屏完整版本对照。未新增浏览器持久草稿、模型改写、跨资料库访问或对外服务。
