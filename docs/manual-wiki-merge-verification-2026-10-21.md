## 本批实现

- 本地库增加 `wikiMergePrepare`（准备历史与当前页的人工合并方案），命令行增加 `wiki merge-prepare`。输入完整本地祖先提交、现有页面键、预期当前修订，以及人工撰写的正文、摘要和可选标题；不调用模型，不改变正式知识或创建证据、提交。
- 返回所需历史页面及依赖、当前目标完整正文，以及所有受影响页面的完整前后预览。显示差异可能有明确的截断标记，完整正文仍可查看。准备要求读取和写入权限，批准仍通过独立的 `wikiApply` 审核操作；没有自动批准参数。
- 保留历史与当前两边的不可变来源、条件、不确定性、冲突状态和更严格的访问与过期限制。旧摘要不作为新的独立证据。现有规则及当前所选目录仍有保守影响，可能进一步限制结果；不能靠合并延长期限或自动消除冲突。
- 签名包含旧提交、历史目标摘要与版本、依赖键、机密选择及现有方案中的当前来源摘要、修订、配置和规则。预览和批准重新验证当前访问、来源、生命周期与签名；修改方案或当前资料需要重新准备。
- 保留原有事务恢复方式，批准时一次写入方案中声明的相关页面和日志。日志仅记录不透明页面编号和旧提交编号，不写私有正文或标题。原封不动的已成功方案重试不重复提交；新准备的方案不是同一次重试。
- 库的批准接口增加可选取消信号，命令行在实际批准期间处理取消。尚未准备提交时取消会回滚；已经准备提交时先安全完成或恢复，成功后的取消错误会包含提交记录。

使用 Agent 记忆设计技能区分原始资料、派生知识及当前使用权限；历史知识不能恢复旧权限，也不能因为被合并就变成新的事实依据。没有复制一套私有资料库或增加专用数据库。使用方法和完整限制见[人工合并指南](manual-wiki-merge.md)。

## 失败、权限与并发检查

- 拒绝缩写或符号提交、不可用历史、错误当前修订、非正式 Wiki 目标、空正文、过大输入、非法字段、无效 Unicode 和 NUL。正常中文及 emoji 的预览和保存正文完整一致。命令行复用现有的有界 UTF-8 文件读取方法，不接受 stdin、网址或自动批准。
- 读取、写入、审核权限及租户、范围分别检查。未显式选择的无关私密名称和摘要不进入方案，所选读取不先解密它们。批准时保留原有宿主全库完整性检查，不能把选择规则解释为禁用该检查或绝不解密其他资料。
- 历史支持被撤回、来源或密钥不可用、当前内容变化、签名或方案被篡改时拒绝；旧冲突、条件及较早期限不能被当前更宽松的版本消除。
- 在真实外层锁删除时注入准备取消或时间推进；单独预览另覆盖最后重新验证、锁清理期间跨历史期限及取消。批准覆盖调用前、事务尚未准备提交、已准备提交以及真实释放锁时取消，分别确认回滚或已完成提交记录。
- 多页写入中途失败会回滚；已经准备提交的事务遇到 Git 故障会保留恢复记录，恢复后原方案重试不再新增提交。取消或期限测试结束后继续正常读写，检查没有残留锁或事务。

所有资料、正文、密钥、故障和资料库均为合成样例，没有读取或迁移用户真实知识。没有调用外部模型。保留的提供商场景使用本机测试服务或替身，不代表真实模型质量。没有新增网页界面，未声称浏览器验收。
