## 本轮交付

- 库与 CLI 支持选择 1–20 个公网 HTTPS 地址，先生成不含正文的指纹预览，再重新检查全部来源后保存。
- 保留原始 UTF-8 内容、BOM、空白、原地址、最终地址、类型、字节数和哈希；HTML 保存为不执行的原文。保存后仍需单独进行 Wiki 编译和审核，不自动批准知识。
- 检查所有 DNS 答案、每次跳转、证书和实际连接地址；拒绝私网、特殊用途地址及 Azure 平台地址；不带认证信息、不使用环境代理。大小、数量、响应头和读取时间均有限制。
- 写入前检查当前权限。取消或失败后报告已完成记录，重试复用未变化的证据；来源变化要求重新预览，不覆盖旧证据。
