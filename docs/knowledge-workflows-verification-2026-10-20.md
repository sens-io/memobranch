## 本轮交付范围

这次完成三项可独立使用的增量，不代表竞品调研中的第二、第三阶段全部完成：

1. **完整记录的上下文预算**：字符上限、可选 token 上限、可替换计数器、常驻与检索分配、身份去重、完整条件和来源、不足时明确省略。CLI、MCP、Harness 支持可选预算；库与 CLI JSON 提供具体计量结果。内置 UTF-8 字节计数是保守估算，不是实际模型用量或账单预测。预算只覆盖返回的上下文正文。
2. **目录资料导入**：明确选择本地目录，先预览文件指纹再应用；有文件、字节、深度、清单大小限制；拒绝符号链接和非 UTF-8 正文。只保存不可变证据，不调用模型、不批准 Wiki。单文件事务支持重复导入去重、进度、取消和重试。库提供公开的 `AbortSignal` 入口；未开放任意服务器文件读取。
3. **来源版本和记录日期查询**：追加导入后保留旧版本，按记录日期筛选和分页，显示当前可用页面的真实引用，并提示旧来源引用需要审核。使用现有来源、依赖、权限、过期与撤回检查。不同作用域或敏感级别的版本分别比较，不用秘密版本影响公共版本状态。

用法见 [使用指南](knowledge-workflows.md)。没有网页抓取、PDF 解析、持久化后台任务队列、事实生效时间查询、历史知识重建、共享只读知识版本、私有变更合并或经验技能导出。这些仍是后续工作，不能用记录日期时间线代替完整历史回答能力。
