# 明确记录知识何时可用（开发源码）

库核心以及命令行、MCP/Harness、网页入口均已通过开发源码的本地验收，
检查和限制见[入口验收记录](knowledge-availability-adapters-verification-2026-10-24.md)。它与按 Git 日期查看
版本、按事实生效时间筛选不同；不表示已发布 npm，也不证明真实模型何时理解了知识。
实际检查和限制见[核心验收记录](knowledge-availability-verification-2026-10-24.md)。

```ts
const recorded = await vault.wikiObserveAvailability({
  pageKeys: ['concept:deployment'], confirm: true,
});
const view = await vault.wikiAsKnownAt({
  pageKeys: ['concept:deployment'], at: recorded.observedAt,
});
```

记录需要读取、写入权限及明确确认。从当前干净 HEAD 读取指定页面，将精确版本、
来源和规则摘要签名后保存为不可变证据，不批准、修改或执行知识内容。不同非公开
作用域要分开记录，敏感等级不能低于来源；敏感／机密资料须明确设置
`includeSensitive` / `includeSecret`，未选中时不解密。保存前会重新检查来源、配置、
HEAD、所属身份和权限，异步检查后还会在最终保存决定前再次同步检查。

`observedAt` 来自宿主本机时钟，不取 Git 提交日期。本机时钟和证明密钥是受信任的
运行条件，并非独立时间认证。记录一个已有页面，不能证明它首次何时可用，更不能
证明 Agent 已读取、理解或相信其中的事实。这里只保留部分明确观察；旧历史、伪造
标记或无法验证的记录会显示未知，丢失证明密钥不会自动重建信任。

查询为每个名称选取不晚于 `at` 的最新可验证记录。同一时刻存在不同内容时显示未知，
不会按文件名选一个。结果说明 `coverage.mode`（本次查找范围），逐项返回 `observed`
或 `unknown`，只有前者包含精确提交内容。查询不调用模型、不新增记录、不写回正式
知识，也不是对未来的建议。

历史读取仍受当前所属身份、操作／资料权限、来源完整性、解密密钥、撤回和到期限制。
选定旧版本不可读时不会退回更旧内容绕过限制，不恢复已擦除的密钥。精确历史页面、
来源与规则摘要由现有本机快照读取检查；本机证明密钥不进入 Git，不作为共享密钥导出。
已复制的明文不能撤回。
生效的内置规则实现也记录摘要，实现变化时不能冒充与观察时一致。
每个名称只绑定自身的完整依赖，无关页面、请求顺序或其他页面的内置规则不能制造冲突。
读取使用持锁期间的一致内容；已开始的查询若与稍后的撤回重叠，可能返回该次读取的版本，
撤回后发起的新查询必须遵守撤回结果。这不表示能够追回已经读出或复制的明文。

限制：1–25 个名称，沿用快照依赖限制；清单最多 200 个文档、160,000 字符；完整查询
结果最多 20 MB。默认扫描最多 2,000 条当前可读、明确选择的原始证据或 20 MB，超限
报错，不截断。也可提供 1–40 个不重复的 `observationIds` 只查该集合，返回结果会说明
没有排除集合外更新或冲突的记录。明确读取私密资料时，扫描范围内其他记录缺失密钥
也会报错，不假装完整返回；现有历史快照完整性要求不放宽。

两个库接口可通过 `signal` 传入真实 `AbortSignal`（取消信号），不接受 JSON 信号、
执行程序或身份覆盖。停止等待不等于撤回已进入完成阶段的事务。若保存完成后权限
失效，错误只附带 `completedAvailability` 的证据 ID 与提交，不返回清单正文；原有
已提交取消信息仍保留。结果不明时先查当前记录及历史，不自动重试。没有数据库、
数据迁移或必填配置变化。

## 命令行与 Agent 工具（开发源码）

```sh
memobranch wiki observe concept:deployment --confirm --root /path/to/vault
memobranch wiki as-known-at concept:deployment --at 2026-10-24T12:00:00Z --root /path/to/vault
# 只查询指定集合，不能排除集合外有更新或冲突的记录：
memobranch wiki as-known-at concept:deployment --at 2026-10-24T12:00:00Z --observations ev-0123456789ab --root /path/to/vault
```

两个命令均支持 `--include-sensitive` / `--include-secret`，仍需当前权限和密钥。
`observe` 必须 `--confirm`，不能覆盖观察时间；`as-known-at` 必须 `--at`，不接受
提交、应用或确认选项。停止信号只取消本次操作；已经完成的事务不能因此撤销。

MCP 与 DeepSeek Harness 提供 `memory_wiki_observe`（`pageKeys`、`confirm:true`、
可选私密资料标志）和 `memory_wiki_as_known_at`（`pageKeys`、`at`、可选
`observationIds` 和私密资料标志）。身份、所属资料库、路径、时间和取消均由宿主管理。
Harness 只有读写权限齐全才注册观察工具，读取工具需要读权限；MCP 调用时仍检查
当前权限。包含转义后的完整结果最多 9 MiB，超限报错而不截断；不自动观察、
调用模型判断或批准知识。

## 本机网页管理（开发源码）

连接本机工作台后，打开“知识可用时间”。每行填写一个页面名称，最多 25 项；
敏感或机密资料必须单独选择，并具有当前权限和密钥。记录当前版本需要完整读写
权限和单独确认，对话框默认选中取消。保存后展示证据 ID、本机观察时间和实际内容
提交；不会自动发起查询。

读取时填写带时区的 ISO 时间，可每行指定一个观察 ID 缩小查找范围。回执中的
“只查本次观察”会明确选中该 ID 和时间后读取。结果逐项区分有观察支持与未知，
展示真实提交、完整页面、来源／规则引用和查找范围限制。此版本结果不包含原始来源
正文或规则说明，来源保留 ID／路径／摘要，规则保留 ID／版本；页面只按普通文字显示，
不执行 HTML；包含 JSON 包装的完整网页结果最多 16 MiB，超限报错，不截断。

修改选择会清除旧结果；停止操作不会自动重试，已经作出提交决定的保存仍可能完成，
应先查原始证据和 Git 历史。保存后的错误只显示经验证的证据 ID 和提交。离开页面
或断开会关闭未确认对话框、取消本页请求、清除表单和结果；迟到响应不能恢复旧内容。
不在浏览器持久保存资料、不增加账号或修改权限、不调用模型或自动批准知识。
