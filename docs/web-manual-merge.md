# Human-reviewed Wiki merges in the Web console

Development-source capability, not yet published to npm. Start the existing local console with `memobranch web --root ./vault` and enter its session token. Choose **知识合并** (Merge review). The console still binds only to `127.0.0.1`; no extra credentials, service or configuration is added.

1. Choose an existing compiled Wiki page and a full local ancestor commit, available in Operations history. Alternatively, [select an explicit recorded time](web-dated-wiki-views.md) and inspect the actual hash returned before merging; the date is not historical knowledge or approval. Select sensitive/secret content explicitly only when intended and currently authorized. Read both complete versions, their conditions, uncertainty and the historical dependency list. If the current head or revisions changed between reads, reload rather than combining mismatched content.
2. Edit the body, summary and optional title. The editor starts with the current authored Markdown, not its generated source-link suffix. Generate a proposal; this calls no model and changes no canonical knowledge. Preparation re-reads the inputs and the comparison, then revalidates a complete signed-plan preview. Inspect every affected page and its full before/after text, not just the bounded line diff.
3. Separately approve and confirm. Approval requires current review authority and the original unchanged signed plan. The result displays the actual Git commit, or reports an already completed exact-plan retry without a new commit. Preparing needs read/write authority; read-only users can compare but cannot prepare or approve.

Changing selection, draft, navigation or session invalidates old approval. After a selection change, an unsaved draft stays visible for editing/copying, but cannot generate or approve against the new selection until versions are reloaded. Reloading asks before replacing it; declining keeps that draft accessible. Requests belong to this page; leaving aborts them and clears its in-memory contents. No local/session browser storage, automatic saving, downloading, persistent browser draft, automatic approval or retry is added. During approval, editing is disabled; closing or cancelling cannot revoke a commit that already completed.

If saving has an uncertain outcome, inspect Operations history first. An explicit **重试原签名方案** retries exactly the retained signed plan, using the core's current access/lifecycle and completed-plan checks. It deliberately does not first run an ordinary preview of already-committed old inputs. It never invents a new plan or automatically retries. An input change discards this retry control. A new proposal is a different review, not a retry.

The fixed-vault authenticated JSON routes are `wiki-snapshot` and `merge-prepare`. They accept no filesystem root/path, credentials, signal, symbolic Git ref or auto-apply field. Ordinary tokens, origin/host checks, permissions, confidential selection, input byte limits, 120-second request cancellation and core Git deadlines remain in force. Complete revision/preparation responses and resubmittable approval envelopes must fit the existing 16 MiB review transport; oversized results fail, not silently truncate full text. No outer adapter lock defers the core's post-cleanup lifecycle check.

All [manual merge restrictions](manual-wiki-merge.md) and [historical reader restrictions](wiki-revision-views.md) still apply. Source text is rendered literally, never executed as HTML. The browser receives plaintext authorized content; no export can be recalled once copied, and signing is not encryption. The mutation host retains whole-vault integrity checks. This is same-vault human review, not Git branch merging, private-vault import, cross-account sharing or proof that the new prose is true. [MCP/Harness tools](agent-manual-merge.md) provide a separate adapter to the same core workflow; no public Internet endpoint is added.

No database, data, vault-format, dependency or configuration migration is required. No push, publication or deployment is implied.
