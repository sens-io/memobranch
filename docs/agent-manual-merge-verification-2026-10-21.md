# Agent Wiki 版本读取与人工合并：验收记录

日期：2026-10-21。项目：`sens-io/memobranch`。来源分支：`kevin/knowledge-expansion`。

## 交付范围

MCP 和 DeepSeek Harness 新增同名工具：`memory_wiki_snapshot`（读取指定本地提交的完整 Wiki 及依赖）和 `memory_wiki_merge_prepare`（根据人工正文准备同资料库历史/当前合并方案）。复用原有核心读取、来源、权限、时间检查和签名方案；准备不调用模型、不批准正式知识。查看完整比较和 `memory_wiki_preview` 后，仍需单独授权调用 `memory_wiki_apply`。详见 [使用说明](agent-manual-merge.md)。

MCP 沿用现有工具列表，在执行时授权；Harness 仅向读者显示版本读取，仅向同时有读取和写入权限的主体显示合并准备。身份、资料库路径、信号、密钥及凭据不接受工具参数覆盖，未知字段和自动应用字段被拒绝。敏感/机密内容需要当前权限、明确选择和可用密钥。签名不是加密，返回的机密正文不能在复制后被追回。

新工具的完整转义文本结果和可再次提交的原方案批准请求上限为 **9 MiB**，为默认 MCP 10 MiB 缓冲区保留空间。超过限制返回 `CONTENT_TOO_LARGE`，不截断正文或返回部分方案。这不是所有既有工具的统一限制，也不能保证宿主模型的上下文足够；人必须确认宿主没有省略批准所依据的内容。

agent-engineering 技能用于检查权限、来源和内容生命周期；open-code-review-delegate 技能用于本地审查文件/规则清单及独立只读审查，没有发送代码到外部审查模型。本批未改网页，也没有扩大共享权限或自动行为。
