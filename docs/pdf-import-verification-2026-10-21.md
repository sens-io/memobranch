## 本批实现

- 显式选择本地文件，先预览再导入。预览只有原件哈希、大小、解析器身份、各页文字哈希与数量、空白页及限制提示，不包含提取正文或原件编码。预览不初始化资料库，不调用模型。
- 导入先检查租户、写权限、范围和敏感等级，再重新读取并解析文件，与完整预览比较。文件、解析器、页文字或预览被修改时拒绝写入。相同输入重试不增加提交；同一路径的新内容作为另一个不可变版本保留。
- 在同一份正式证据中分开保存原始 PDF 字节和带页码的提取文字，使用新的 `digestVersion: 3`（PDF 证据摘要版本）。原件、正文及解析元数据绑定验证，继承现有加密、事务恢复和 Git 历史。没有增加附件存储或放宽远端文件类型。
- `previewPdfImport`、`applyPdfImport` 是本地预览和导入接口；`readPdfOriginal` 经已有授权读取返回原始字节。CLI 增加 `import pdf-preview` 和 `import pdf-apply`。不增加 HTTP 上传、服务器路径读取、MCP/Harness 路径工具或目录自动发现。
- PDF 导入仅保存证据，不自动提炼或批准知识。Wiki 仍按导入、查询、检查分开执行，并要求明确批准写入。Wiki 模型输入及 MCP/Harness 的 `memory_get`（记录读取工具）省略原件编码；有权限的本地完整记录读取仍可取得原件。

采用 Agent 记忆设计技能来保持原件与批准知识分开；PDF 技能仅用于检查自制测试样例的页面，不作为生产解析依赖。使用方法与完整限制见[本地 PDF 导入指南](pdf-import.md)。

## 异常、权限与来源验证

- 拒绝超出 5,000,000 字节、100 页、100,000 个文字项或 200,000 个提取字符的输入；字符限制包含证据头部，资料库更小的正文限制仍有效。覆盖损坏、密码加密、完全无文字、符号链接及非普通文件。
- 校验原件字节数、哈希、编码、解析元数据、完整文字摘要及空白页列表；原件丢失、篡改或摘要版本降级均不能作为普通证据通过。普通文字证据及原有版本迁移保持兼容。
- 租户、权限、范围和敏感等级检查在导入读取源文件之前执行。受保护原件与正文一起加密，越权读取不能返回原件。单独销毁合成加密证据的密钥后，原件与正文都不可读。
- 合成故障验证写入回滚和已准备提交的恢复记录；恢复后仍可取得完全相同的加密原件。真实本机裸 Git 远端测试覆盖推送、克隆后缺密钥拒绝、恢复密钥、重建索引及拉取新版本后保留两版原件；未连接用户远端或真实资料库。
- 中文文字映射测试保留连续中文，不人为添加空格。混合文字与空白页保留原页码。带动作 URL 的 PDF 不触发测试服务器请求；解析不执行脚本、动作或跟随外部链接。
- 自制三页样例经独立页面渲染并逐页查看：第一页和第三页有预期文字，第二页空白。这仅证明测试输入的可视内容；不证明任意 PDF 的版面、表格、图片或事实提取质量。

所有资料库、原件、密钥及远端均为合成测试资料，没有读取或迁移用户真实资料，没有调用外部模型。安装验证中沿用的模型场景也是本机测试服务或替身，不代表外部模型质量。

## 能力边界与交付状态

仅支持显式本地文字层提取，没有 OCR、扫描件识别、版面或表格重建、签名验证、图片理解、表单解释或嵌入附件提取；完全没有可提取文字的 PDF 拒绝导入。保留精确原件意味着也保留其中隐藏内容及作者元数据，必须按整份原件选择敏感等级；省略模型输出不是原件清洗。

解析期限默认 10 秒，可设 1–120,000 毫秒，只覆盖工作线程解析，不是文件访问、授权、等待锁或 Git 提交的总期限。工作线程在成功、错误、超时或取消后终止并等待结束；已准备完成的提交遵循原有安全完成及已提交操作错误规则。JavaScript 堆限制不是所有原生内存或 ArrayBuffer 的硬限制，也不是操作系统隔离。本功能不能直接作为不可信多租户上传服务开放。

证据沿用不可变来源保留规则：撤回或删除衍生记忆不删除原始证据/PDF。本批没有新增来源删除接口。销毁加密证据密钥会使两种表示不可读，但不会删除 Git 中的密文及外部副本。旧进程不认识版本 3，导入前应停止旧读写进程，不可与新版本混用。

数据库变更：无。数据迁移：新增 PDF 使用证据摘要版本 3，普通旧证据不自动改写；未对真实资料执行迁移。配置变更：无新配置、环境变量或凭据，无资料库或缓存版本变化。依赖变更：固定新增 `unpdf@1.7.0` 及锁文件，生产审计为 0 个已知漏洞。
