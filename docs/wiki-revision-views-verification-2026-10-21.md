## 本批实现

- 本地库增加 `wikiSnapshot`（指定提交的知识读取），CLI 增加 `wiki snapshot`。显式选择 1–25 个页面键及完整的本地祖先提交编号，返回旧页面的完整正文、元数据和实际修订，另列当前修订、当前检查所用提交及时间。
- 历史链接和依赖全部读取，循环只返回一次；来源仅返回身份、路径与哈希，规则仅返回身份及版本，不输出原始资料正文、PDF 原件、规则指令或配置。普通记忆使用 `legacy:<memory-id>` 选择，仍保留其条件和时间标注。
- 复用 Wiki 的来源、规则、关联页面验证，并对历史依赖逐项执行当前权限、敏感级别、生命周期和密钥检查。当前根页面已经不再引用的旧依赖，也不能省略检查。历史正文不是当前建议或事实有效期的证明。
- 只读 Git 对象，不切换工作目录，不重置、合并或修改引用、索引、正式文件或密钥，不调用模型。忽略 Git 替换对象，拒绝非祖先、其他资料库/租户、旧式历史改写及部分克隆配置，避免提交编号被替换内容或隐式网络读取改变。
- 已准备提交的事务、同步或删除恢复未处理时拒绝读取。读取占用现有写锁；当前受管理资料不干净时拒绝。释放锁后再次检查时间与取消，不返回部分结果。

使用 Agent 记忆设计技能区分原始资料、已批准知识及当前访问权；旧知识不能用来恢复旧权限。没有另建快照数据库或复制一份私有资料。使用方法与完整限制见[指定提交读取指南](wiki-revision-views.md)。

## 边界与并发证据

- 覆盖完整提交、非提交对象、缩写/符号引用、非祖先、缺失页面、重复键、脏资料、历史租户不符及不合法来源路径。真实 Git 替换对象不能替换旧视图正文；旧式历史改写和部分克隆配置在对象读取前拒绝。
- 核对当前与历史两侧的范围和敏感级别。未选择机密内容时不先解密；当前低敏感级别的新正文不能用来读取旧机密正文。撤回、当前失效、旧修订已经到期、来源或规则不可用、密钥销毁均拒绝读取。
- 核对循环依赖、历史依赖已从当前根页面移除但现已撤回的情况，以及所有页完整返回或整次失败。50 页、200 存储记录、10 MB 单个对象及 20 MB 总存储字节限制包含失败断言，没有静默截断。
- 真实读锁期间发起的正常写入等待读取结束；取消失败后继续读取/写入成功。锁清理注入保留真实 `settledRead` 和 `withFileLock`（现有一致读取和文件锁），仅在真实删除锁文件时推进测试时钟或取消信号；测试恢复函数后再执行正常写入，证明没有残留锁。
- PDF 来源参与校验，但快照结果不含原件字段或编码。旧普通记忆与当前修订都必须在读取时符合生效日期，不能借旧版本恢复现在不允许使用的记录。

所有资料库、文件、密钥、正文和故障均为合成资料，没有读取或迁移用户真实资料。没有调用外部模型；安装检查保留的现有提供商场景使用本机测试服务或替身，不代表真实模型质量。没有新网页界面，未将自动化检查写成浏览器验收。
