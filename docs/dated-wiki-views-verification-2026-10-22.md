# 按 Git 记录时间查看 Wiki：验收记录

日期：2026-10-22。项目：`sens-io/memobranch`。来源分支：`kevin/knowledge-expansion`。

## 交付范围

在原来的 Wiki 版本读取中新增 `at` 日期选择，与原 `commit` 完整提交 hash 必须二选一。库接口、CLI、MCP、DeepSeek Harness 和带身份验证的 HTTP 均已支持；不增加工具名称、网页日期控件或自动写入。原 hash 调用仍返回原有结构，不增加 `selection` 字段。详见 [使用说明](dated-wiki-views.md)。

选择规则：从当前本地 HEAD 沿每次提交的第一个父提交向前查看，最多检查 2000 条，返回第一条 Git **提交者时间**不晚于请求时间的记录。不是按全仓库时间排序；作者时间、来源时间、页面更新时间和事实有效期不参与选择。第 2001 条只用于发现超过上限，不参与选择。时间相同按祖先顺序选择；非单调时钟和合并的另一父分支不会改变规则。

Git 时间可以被补写或改写，因此结果不是“Agent 当时知道什么”、历史事实真伪判断或历史模型回答。返回实际 hash、规范化的时间选择信息及明确警告；需要可重复读取时应固定实际 hash。未来日期也只能选中已经存在的本地提交。未找到、超过上限、缺失页面或所需依赖时拒绝，不抓取远端、不换用其他版本、不替换成今日正文。

日期选择和原版本读取在同一次读取保护内完成。当前身份、租户、读取权限、作用域、敏感级别、明确选择私密页面、来源、密钥和生命周期限制继续有效；历史普通记忆也必须在**现在**有效。早日期不能恢复已撤回、失效或擦除密钥的内容。取消、外部改动以及真实锁释放后的最终检查仍生效。没有模型调用、来源改写、检出版本、引用/索引改动或自动批准。

agent-engineering 技能用于检查来源、当前权限与生命周期，避免把历史正文当成当前可用知识；open-code-review-delegate 技能用于本地文件/规则清单和独立只读审查，没有向外部审查模型发送代码。
